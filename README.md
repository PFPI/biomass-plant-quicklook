# Planned Changes
 
1. Users should be able to set their distance bands instead of by default going up to 200 miles.
2. We should have a suggested default value plus suggested low/high range values. Like Efficiency 24% default but could range 22-29% or something similar. This would be exceptionally valuable in the LAND subcategory 
3. For the amount of wood, instead of a dropdown, let's set the default value by our calculations and then they can manually change it. WAY less complex.
4. For type of wood, we should do pine only, hardwood only, everything. 
5. I see thinning estimates in the code but not in the public view. Can we let them choose % from thinning / % from clearcut and then give them the low/high values for each to modify?
6. We should accordion these subcategories so they're not overwhelming. 
7. We should keep all of the defaults, low/high ranges, etc. in one sub file, not split it between App and biomass.
